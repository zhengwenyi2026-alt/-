隔空传 SkyDrop

免费 · 开源 · 免注册 · macOS 与 Windows 互传

把文件拖进窗口，按「开始传送」，文件就出现在对方电脑的下载目录里——体验对齐苹果「隔空投送」，但 Mac 和 Windows 之间也能互传。 一台设备点「创建房间」拿到 6 位房间码，另一台输入房间码即可连接。局域网内不经过任何服务器，文件不出你的路由器； 两台设备不在同一个网络时，还能挂一个自己的中继跨网段传输。

适用设备文件体积

不确定选哪个？Mac 按「关于本机 → 芯片」判断：Apple M 系列选 arm64，Intel 选 x64； Windows 一律用 Setup-…x64.exe（想要免安装就选 Portable）。 下载文件名用的是应用的英文名 SkyDrop，安装完成后开始菜单与「应用程序」里的名字是「隔空传」，是同一个应用。

首次打开

macOS：安装包未做开发者证书签名与公证，Gatekeeper 会拦一次。任选一种放行：访达里右键（按住 Control 点击）→ 打开 → 打开；或「系统设置 → 隐私与安全性」底部点「仍要打开」；或终端执行

xattr -dr com.apple.quarantine "/Applications/隔空传.app"

Windows：SmartScreen 提示「Windows 已保护你的电脑」→ 点更多信息 → 仍要运行。

防火墙：第一次传输时 macOS 会问「是否允许接收传入网络连接」→ 点允许；Windows 弹窗勾选专用网络即可，不需要放开公用网络。

怎么用（三步）

  • 两台电脑连同一个 Wi-Fi / 同一路由器。接收方点「创建房间」，界面出现 6 位房间码（例如 K7M-3XQ）。
  • 发送方输入房间码加入，也可以点「扫描附近房间」直接选，或在「高级」里手填 IP:端口。
  • 主机点「允许」，发送方把文件或文件夹拖进窗口、点「开始传送」，接收方点「接收」，文件落到 ~/Downloads/隔空传（Windows 为 %USERPROFILE%\Downloads\隔空传）。

房间是双向通道，连上之后任何一方都能发；一个房间最多 8 台设备。文件夹会保留目录层级递归传输，同名文件不会覆盖（自动改成 报告 (1).pdf）。

不在同一个网络也能传

设置里的「跨网传输」默认关闭。打开后填一个你自己部署的 WebSocket 中继地址（Cloudflare Workers / Vercel / 任意一台有公网地址的机器），房主把房间挂到中继上，访客在任意网络输入同一个房间码就能加入——之后的接收确认、进度、校验和局域网完全一样。Cloudflare 部署只需两条命令，免费额度对偶尔传文件完全够用。

部署与排错说明：relay/README.md。没有中继时应用没有任何出站连接。

它是怎么保证不出问题的

  • 完整性校验两端各自单遍增量 sha256，落盘后比对，不一致直接判失败并删掉临时文件，不会留下「看起来成功」的坏文件。
  • 断点安全先写 *.part，校验通过再原子改名，中断不会污染已有文件。
  • 双向人工确认加入房间要主机点「允许」，发送文件要对方点「接收」，180 秒无人确认自动超时。
  • 房间码抗暴力6 位 × 32 字符集约 10 亿种组合，同一来源连续输错 8 次直接拉黑。
  • 路径穿越防护文件名与相对路径剔除 ..、绝对路径、Windows 保留名与控制字符，落盘前再做 realpath 校验。
  • 只接受私网地址局域网模式默认拒绝公网来源直连，「允许公网地址」是另一个需要单独勾选的开关。
  • 5 种界面语言简体中文 / 繁體中文 / English / 日本語 / 한국어，跟随系统语言，界面里即时切换、无需重启。
  • 零依赖打包成自包含的 .dmg / .exe，双击即用，不需要装 Node 或 Python。

请知情的几点

传输内容未加密。局域网直连时链路在你自己的路由器内；走中继时中继做的是字节透传，因此中继的运营方（Cloudflare、Vercel 或那台机器的管理员）理论上能看到文件名与文件内容。中继代码本身不写盘、不记日志、配对关系只存内存且断开即清，但这不等于加密。传敏感文件请优先用自建中继，端到端加密是后续项、当前版本尚未实现。

没有断点续传：中断后需重传整个文件。单次任务上限 5000 个文件，目录递归最深 16 层。

公共 Wi-Fi 注意：开了「AP 隔离 / 客户端隔离」的网络会屏蔽设备互访，任何局域网工具都传不了——那正是跨网传输要解决的场景。

校验和（sha256）

下载后可以先比对再安装，例如 shasum -a 256 SkyDrop-1.0.0-arm64.dmg（Windows：certutil -hashfile 文件名 SHA256）。
